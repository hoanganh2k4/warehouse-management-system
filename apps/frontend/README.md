# Smart WMS — Frontend

React + TypeScript + Vite dashboard for the Smart Warehouse Management System.

Project-wide setup and architecture live in the root of the repo — see
[`/README.md`](../../README.md) and [`/docs`](../../docs).

## Commands (run from repo root)

```bash
npm run frontend          # start the dev server (proxies /api to localhost:3000)
npm run --workspace=frontend build
npm run --workspace=frontend lint
```
