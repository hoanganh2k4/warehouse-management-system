Bạn là trợ lý lập trình frontend React/TypeScript. Tôi cần thêm hiển thị hạn sử dụng + badge màu cảnh báo
(OK/WARNING/CRITICAL/EXPIRED) ở trang Tồn kho và popup chi tiết Slot trong Racking.

BỐI CẢNH:
- Backend `GET /inventory` giờ trả thêm field `expiryDate` (string ISO), `expiryStatus`
  ('OK'|'WARNING'|'CRITICAL'|'EXPIRED'), `daysUntilExpiry` (number) cho mỗi item — nhưng type
  `InventoryItem` (`apps/frontend/src/types.ts`) và component `InventoryTable.tsx` chưa dùng các field này.
- `apps/frontend/src/pages/racking/components/SlotDetailDialog.tsx` hiện chỉ hiển thị sản phẩm đang ở slot
  (`product`), không có thông tin lô hàng/hạn sử dụng. Muốn lấy dữ liệu này, gọi
  `inventoryService.getInventory({ slotId: slot.id })` — API `GET /inventory` đã hỗ trợ filter theo
  `slotId` (field này đã có sẵn trong `GetInventoryParams`), không cần API mới.

MỤC TIÊU TASK (CHỈ LÀM ĐÚNG VIỆC NÀY):
1. Trong `apps/frontend/src/types.ts`, thêm 3 field vào `InventoryItem`:
   `expiryDate: string`, `expiryStatus: 'OK' | 'WARNING' | 'CRITICAL' | 'EXPIRED'`,
   `daysUntilExpiry: number` (đặt trước `updatedAt`).
2. Tạo file mới `apps/frontend/src/utils/expiry.utils.ts`, export:
   - `type ExpiryStatus = 'OK' | 'WARNING' | 'CRITICAL' | 'EXPIRED'`
   - `getExpiryBadgeClass(status: ExpiryStatus): string` — trả về `'expiry-badge is-ok'`,
     `'expiry-badge is-warning'`, `'expiry-badge is-critical'`, `'expiry-badge is-expired'` tương ứng.
   - `getExpiryLabel(status: ExpiryStatus, daysUntilExpiry: number): string` — EXPIRED trả
     `Đã hết hạn {abs(daysUntilExpiry)} ngày`; CRITICAL/WARNING trả `Còn {daysUntilExpiry} ngày`; OK trả
     `Còn hạn`.
   - `formatDate(value: string): string` — format `dd/mm/yyyy`.
3. Trong `apps/frontend/src/components/InventoryTable.tsx`: thêm cột `<th>Hạn sử dụng</th>` (sau cột "Số
   lượng", trước "Cập nhật lúc") — thêm cả ở bảng skeleton loading (thêm `<td>` skeleton tương ứng) lẫn bảng
   dữ liệu thật (thêm `<td>` hiển thị badge dùng `getExpiryBadgeClass`/`getExpiryLabel`/`formatDate` vừa
   tạo). Import các hàm này từ `'../utils/expiry.utils'`.
4. Trong `apps/frontend/src/pages/racking/components/SlotDetailDialog.tsx`:
   - Thêm `useState`/`useEffect` (import từ 'react'): khi `slot.id` thay đổi, gọi
     `inventoryService.getInventory({ slotId: slot.id, limit: 10 })` (import `inventoryService` từ
     `'../../../services/inventory.service'`), lưu `result.items` vào state `slotBatches`
     (`InventoryItem[]`), có state `slotBatchesLoading` (boolean).
   - Thêm 1 mục mới trong `<dl className="warehouse-map-popup-list">`, đặt SAU mục "Hàng hoá", TRƯỚC
     `</dl>`: hiển thị "Đang tải..." khi loading, "Không có lô hàng" khi rỗng, hoặc danh sách các batch với
     badge màu (dùng `getExpiryBadgeClass`, `getExpiryLabel`, `formatDate`).
5. Thêm CSS cho class `.expiry-badge` và 4 biến thể `.is-ok` (xanh lá), `.is-warning` (vàng), `.is-critical`
   (cam), `.is-expired` (đỏ) vào file CSS chung của dự án (tìm đúng file đang định nghĩa
   `.slot-status-badge` để thêm cạnh đó, giữ đúng convention màu/style hiện có của dự án — bạn xem file CSS
   tôi dán bên dưới để chọn đúng vị trí thêm).
