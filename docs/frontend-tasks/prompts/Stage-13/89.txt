Bạn là trợ lý lập trình backend NestJS/Prisma. Tôi cần tạo 1 util dùng chung để tính trạng thái hết hạn
(expiryStatus), và gắn vào response của Batch API + Inventory API.

BỐI CẢNH:
- `apps/backend/src/inventory/inventory.service.ts`: hàm `toInventoryView` hiện KHÔNG trả `expiryDate` (vì
  `select` của `batch` chỉ lấy `batchCode` + `product`, thiếu `expiryDate`). Cần thêm `expiryDate` vào select
  và trả thêm `expiryStatus`/`daysUntilExpiry` tính từ đó.
- `apps/backend/src/batches/batches.service.ts`: `findAll`/`findOne` đã trả `expiryDate` thô (qua include
  nguyên Batch), nhưng chưa có trạng thái tính sẵn.
- Ngưỡng cảnh báo phải khớp với ngưỡng 30 ngày mà `dashboard.service.ts` đang dùng cho biến `expiringSoon`
  (xem đoạn `batch.count({ where: { expiryDate: { lte: ... 30 * 24 * 60 * 60 * 1000 ... } } })`), để không
  tạo thêm 1 ngưỡng lệch pha.

MỤC TIÊU TASK (CHỈ LÀM ĐÚNG VIỆC NÀY):
1. Tạo file mới `apps/backend/src/common/utils/expiry.util.ts`:
   ```ts
   export const EXPIRY_WARNING_DAYS = 30;
   export const EXPIRY_CRITICAL_DAYS = 7;
   export type ExpiryStatus = 'OK' | 'WARNING' | 'CRITICAL' | 'EXPIRED';
   export function getExpiryStatus(expiryDate: Date): { status: ExpiryStatus; daysUntilExpiry: number }
   ```
   Logic: so sánh theo NGÀY (bỏ giờ/phút/giây bằng setHours(0,0,0,0) cho cả hôm nay và expiryDate trước khi
   trừ) — < 0 ngày = EXPIRED, <= 7 ngày = CRITICAL, <= 30 ngày = WARNING, còn lại = OK.
2. Sửa `inventory.service.ts`:
   - Thêm `expiryDate: true` vào `batch: { select: { ... } }` ở CẢ HAI chỗ dùng trong `findAll()` và
     `findOne()`.
   - Sửa type tham số và nội dung hàm `toInventoryView` để nhận `batch.expiryDate`, gọi `getExpiryStatus`,
     trả thêm 3 field mới vào object trả về: `expiryDate`, `expiryStatus`, `daysUntilExpiry`.
3. Sửa `batches.service.ts`:
   - Trong `findAll()`, map từng item trong mảng `items` trước khi `paginate(...)`, gắn thêm
     `expiryStatus`/`daysUntilExpiry` từ `getExpiryStatus(batch.expiryDate)`.
   - Trong `findOne()`, làm tương tự cho object `batch` trước khi return.
