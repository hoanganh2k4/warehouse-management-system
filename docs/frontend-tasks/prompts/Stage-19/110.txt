Bạn là trợ lý lập trình frontend React/TypeScript. Tôi cần thêm 1 field KHÔNG BẮT BUỘC "Hạn sử dụng dự
kiến" vào form đặt lịch nhập.

BỐI CẢNH:
Backend `POST /schedules/inbound/preview` và `POST /schedules/inbound` giờ chấp nhận thêm field optional
`expiryDate` (string, ISO date) — nếu có, dùng để tính gợi ý vị trí FEFO chính xác hơn; nếu không có, hệ
thống tự dùng `scheduledDate` như trước (không đổi hành vi cũ). `InboundScheduleModal.tsx` hiện có các field
`scheduledDate`, `scheduledTime`, `supplierId`, `productId`, `quantity`, `batchCode`, `note` — có 1
`useEffect` tự động gọi API preview khi `productId`/`quantity`/`scheduledDate` đổi, và 1 `handleSubmit` gọi
API tạo lịch thật.

MỤC TIÊU TASK (CHỈ LÀM ĐÚNG VIỆC NÀY):
1. Trong `apps/frontend/src/types.ts`, thêm `expiryDate?: string;` vào CẢ HAI type
   `InboundSuggestionPreviewPayload` và `CreateInboundSchedulePayload`.
2. Trong `InboundScheduleModal.tsx`:
   - Thêm `expiryDate: string;` vào `type FormState`, thêm `expiryDate: ''` vào `INITIAL_FORM`.
   - Thêm `form.expiryDate` vào dependency array của `useEffect` gọi API preview.
   - Trong object gửi lên API preview, thêm `expiryDate: form.expiryDate || undefined`.
   - Trong `payload` gửi lên API tạo lịch (`handleSubmit`), thêm `expiryDate: form.expiryDate || undefined`.
   - Thêm field input date trong JSX, đặt NGAY SAU field `scheduledDate` hiện có, theo đúng cấu trúc
     `form-field`/`form-label`/`form-input` các field khác đang dùng:
     ```tsx
     <div className="form-field">
       <label className="form-label" htmlFor="in-expiryDate">
         Hạn sử dụng dự kiến (nếu đã biết)
       </label>
       <input
         id="in-expiryDate"
         type="date"
         className="form-input"
         value={form.expiryDate}
         onChange={(e) => updateField('expiryDate', e.target.value)}
       />
     </div>
     ```

QUY TẮC BẮT BUỘC:
