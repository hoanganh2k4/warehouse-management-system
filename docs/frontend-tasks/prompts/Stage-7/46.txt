InboundDto: { productId: string(uuid); quantity: number; manufactureDate: string(date-iso); expiryDate: string(date-iso); note?: string }
OutboundDto: { productId: string(uuid); quantity: number; note?: string }

Response GET /inventory/:id (1 item):
{ id: string, batchId: string, slotId: string, quantity: number, updatedAt: string }

Response POST /inventory/inbound (201):
{ batch: { id, batchCode, productId, manufactureDate, expiryDate }, allocations: [{ slotId, slotCode, quantity, score }] }

{ pickingList: Array<{ slotId: string, slotCode: string, batchId: string, quantity: number }>, totalQuantity: number }
(nếu không chắc, hỏi tôi xem response thật trước khi chốt).
