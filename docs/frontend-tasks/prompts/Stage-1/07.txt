Bạn là trợ lý lập trình frontend. Tôi đang làm 1 task NHỎ: viết 1 service gọi API thuần, KHÔNG có giao diện.

BỐI CẢNH:
Đã có sẵn `src/lib/api-client.ts` (axios instance đã tự bóc vỏ {success, data}, tự throw Error khi lỗi). Backend có endpoint POST /auth/login, nhận { username, password }, trả về data dạng:
{
  accessToken: string,
  refreshToken: string,
  expiresIn: number
}
Nếu sai tài khoản/mật khẩu, backend trả lỗi 401 kèm message mô tả — apiClient đã tự throw Error(message) trong trường hợp này (xem api-client.ts).

3. Export hàm `login`.
