Tôi cần tạo file mới apps/frontend/src/services/zone.service.ts (React + TypeScript + axios).

Bối cảnh:
- apiClient (../lib/api-client) đã cấu hình sẵn, tự gắn Bearer token, tự bóc envelope {success, data}.
- Type Zone, CreateZonePayload, UpdateZonePayload đã có trong ../types.
- Backend endpoints (đều yêu cầu đăng nhập):
  GET /zones -> trả mảng Zone[] THUẦN (không có meta/pagination)
  GET /zones/:id -> Zone
  POST /zones (body CreateZonePayload) -> Zone
  PUT /zones/:id (body UpdateZonePayload) -> Zone
  DELETE /zones/:id -> Zone

Yêu cầu:
1. Export zoneService với 5 hàm: getAll(), getById(id), create(payload), update(id, payload), remove(id).
2. getAll trả về Promise<Zone[]> (mảng thuần, KHÔNG bọc trong {items, meta}).
3. Dùng đúng method HTTP như trên (get/post/put/delete) qua apiClient.
4. Trả về toàn bộ nội dung file.
