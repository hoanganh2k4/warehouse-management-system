Tôi cần tạo file mới apps/frontend/src/services/rack.service.ts (React + TypeScript + axios).

Bối cảnh:
- apiClient (../lib/api-client) đã cấu hình sẵn, tự gắn Bearer token, tự bóc envelope {success, data}.
- Type Rack, CreateRackPayload, UpdateRackPayload đã có trong ../types.
- Backend endpoints (đều yêu cầu đăng nhập):
  GET /racks?zoneId= -> trả mảng Rack[] THUẦN (không có meta/pagination)
  GET /racks/:id -> Rack
  POST /racks (body CreateRackPayload) -> Rack
  PUT /racks/:id (body UpdateRackPayload) -> Rack
  DELETE /racks/:id -> Rack

Yêu cầu:
1. Export rackService với 5 hàm: getAll(zoneId?: string), getById(id), create(payload), update(id, payload), remove(id).
2. getAll trả về Promise<Rack[]> (mảng thuần, KHÔNG bọc trong {items, meta}).
3. Dùng đúng method HTTP như trên (get/post/put/delete) qua apiClient.
4. Trả về toàn bộ nội dung file.
